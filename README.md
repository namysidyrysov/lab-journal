# lab-journal

Редактор лабораторного журнала. Работает в браузере, ничего устанавливать не нужно.
Результат работы — обычная папка проекта: `journal.html` + `images/`. Её можно отправить коллеге zip-архивом, он откроет `journal.html` двойным кликом.

> Статус: в разработке (шаг 1 — каркас).

## Требования
- Браузер Chrome или Edge (нужен доступ к папкам на диске).

## Запуск
1. Скачайте репозиторий (Code → Download ZIP) или выполните `git clone`.
2. Откройте `index.html` в Chrome.
3. Создайте проект или откройте существующую папку проекта.

## Как хранятся данные
Один проект — одна папка на диске:

```
Мои журналы/
  Название-проекта/
    journal.html   ← готовый журнал (и данные внутри него)
    images/        ← картинки
    backups/       ← автоматические копии
```

Папки проектов лежат вне репозитория. Редактор один, проектов может быть сколько угодно.

## Структура репозитория
```
index.html   редактор (открывать в браузере)
src/         скрипты и стили
examples/    демо-журнал
```
